# 0.0.2.7-beta — Thermal Refinement

## Main Theme

Expand the Molten Rotor Furnace into a more controllable part of a Create factory without adding another oversized machinery system.

The update focuses on:

* monitoring furnace temperature;
* reacting to dangerous heat levels;
* giving existing materials new uses;
* adding a balanced way to heat items while they travel;
* improving extreme-temperature furnace feedback.

This update should remain smaller than **0.0.2.6-beta — Ashen Resonance**.

# Main Features

## 1. Thermal Relay Switch

The Thermal Relay Switch is the primary feature of 0.0.2.7.

It links to a Molten Rotor Furnace, watches its current temperature, and emits a redstone signal when a configured condition is met.

### Uses

Players can use it to:

* activate a clutch when the furnace reaches operating temperature;
* disable fuel insertion before overheating;
* trigger warning lamps;
* control funnels and belts;
* enable a mixer only when sufficient heat is available;
* shut down parts of a factory during cooldown.

### Linking

1. Hold the Thermal Relay Switch item.
2. Right-click a Molten Rotor Furnace to select it. The create default glowing bow will illuminate over the furnace
3. Place the switch.
4. Configure its threshold and operating mode.

The linked furnace coordinates are stored on the item and displayed in its tooltip.

Breaking the original furnace invalidates the connection. Placing another furnace at the same coordinates does not automatically restore the old link.

### Operating Modes

The switch can cycle between:

* **Above Threshold**
* **Below Threshold**
* **Within Range**
* **Outside Range**

The initial release may use only **Above Threshold** and **Below Threshold** if the range modes add too much interface work.

### Configuration

Right-clicking opens or cycles the configured temperature.

* right-click: increase threshold by 50°C;
* sneak-right-click: decrease threshold by 50°C;
* wrench interaction: cycle operating mode.

Possible temperature range:


### Engineer’s Goggles Information

### Visual States

* dark and inactive when unlinked;
* dim orange when linked;
* bright orange when approaching the threshold;
* red when actively outputting a signal;

## 2. Combustion Belt

The Combustion Belt heats items while they travel across it.

It should not replace furnaces, blasting, smoking, bulk processing, or ordinary Create recipes. Its purpose is to provide continuous heating for selected materials while preserving the importance of existing machines.

## Core Behaviour

A Combustion Belt is a heat-resistant belt component installed over an existing Create belt segment.

Items gain thermal exposure while travelling across active Combustion Belt segments.

The belt only operates while supplied with sufficient heat from a nearby Molten Rotor Furnace.

### Heat Connection

A belt segment is active when:

* it is directly above the Molten Rotor Furnace’s valid heating teir, HEATED;
* or it is within a short horizontal range of the furnace;
* or it is connected through a dedicated heat input block added later.

For 0.0.2.7, direct proximity is the safest implementation.

Suggested range:

```text
Maximum distance: 3 blocks from the Molten Rotor Furnace
```

## Balanced Processing System

The belt does not instantly convert every item that touches it.

Each supported item has a required amount of **thermal exposure**.

Thermal exposure increases only while the item is moving across an active Combustion Belt.

Example:

```text
1 active segment crossed = 1 heat unit
```

A recipe may require:

```text
2 to 8 heat units
```

This means the player must construct a belt long enough for the selected process.

### Example

```text
Unfinished Filament
Required exposure: 4 heat units
Result: Cinder Filament
```

The item must cross four active Combustion Belt segments before completing.

## Anti-Exploit Rules

To keep the belt balanced:

* stationary items do not gain heat;
* depots do not count as continuous belt exposure;
* reversing one item repeatedly over the same segment does not generate unlimited progress;
* exposure slowly decays after leaving the heated belt;
* only registered Combustion Belt recipes can process;
* Leaving items on the belt too long burns them into spent ash If an item stays on the belt too long, it should not automatically burn or disappear unless a specific recipe defines an overheat result.;
* vanilla smelting recipes are not accepted automatically;
* each item stack is processed separately;
* belt speed affects travel time but not the required number of segments;
* only higher heat teirs can speed up heating;
* faster belts do not reduce recipe cost.

### Exposure Decay

When an item leaves the Combustion Belt, say to be transferred to another belt via ejector, but that item hasnt finished heating to the new item:

```text
Thermal exposure begins decaying after 2 seconds.
```

Possible decay:

```text
1 heat unit lost every second.
```

This allows short gaps while preventing players from storing permanently heated intermediates.

## Processing Failure

If an item leaves the belt before receiving enough exposure:

* it remains unchanged;
* its stored exposure begins to decay;
* it may resume processing if returned quickly.



## Supported Recipe Types

The Combustion Belt should support selected existing and new recipes.

### Existing-material uses

```text
Wet or unfinished ceramic component
→ Combustion Belt
→ Fired ceramic component
```

```text
Unfinished Filament
→ Combustion Belt
→ Cinder Filament
```

```text
Unrefined Rubber
+ required prior ingredient processing
→ Combustion Belt
→ Vulcanized Rubber
```

The belt should not accept loose multi-item combinations directly. Mixing and assembly should still happen before thermal belt processing.

### Vanilla and Create Compatibility

Possible carefully selected compatibility recipes:

```text
Raw Clay Block
→ Combustion Belt
→ Terracotta
```

```text
Wet Sponge
→ Combustion Belt
→ Sponge
```

These should require long exposure and provide no experience.

Avoid supporting:

* all furnace recipes;
* all blasting recipes;
* ores into ingots;
* food cooking;
* automatic charcoal production;
* recipes already handled efficiently by Encased Fans.

## Heat Tiers

Different recipes may require different furnace heat states.

### Heated

Suitable for:

* drying;
* curing;
* low-temperature ceramic preparation.

### Superheated

Suitable for:

* Cinder Filament;
* advanced rubber curing;
* reinforced materials.

### Combustion

Reserved for later highly resistant materials.

The belt stops progressing a recipe if the furnace falls below the required heat tier.

Existing exposure is retained briefly before decay begins.

## Belt Appearance

The Combustion Belt should visually resemble Create’s belt while remaining identifiable.

Suggested appearance:

* dark heat-resistant belt surface;
* Obsidian Fiber or ceramic edging;
* glowing seams while active;
* brighter glow at higher heat tiers;
* subtle sparks at superheated temperatures;
* no constant fire covering the items.

# Molten Rotor Furnace Improvements

## 5. Extreme Heat Visuals

Improve furnace feedback near maximum temperature.

At very high temperatures:

* bright heat distortion appears around the opening;
* smoke output increases;
* seams and internal parts glow more intensely.

At approximately:

```text
1,500°C and above
```

the furnace enters a warning presentation state.

At:

```text
1,599°C
```

the strongest visual state appears.

This should primarily be visual and informational. Do not make the furnace explode automatically during ordinary operation.

## TNT Overload Interaction

TNT may remain an unstable high-energy fuel.

When TNT pushes the furnace toward extreme temperature:

* fire bursts from the opening;
* the warning sound plays;
* the Thermal Relay Switch can detect the threshold;
* particles clearly indicate dangerous operation.

Any explosion chance should remain configurable or intentionally limited.
For inserting tnt at 1500+, explosion will happen with fire animation and sound

# Deferred Features

The following ideas should not be part of 0.0.2.7.

## Heat Relay Network

Useful, but adds network traversal, branching, heat loss, endpoint validation, rendering, and balancing.

Reserve for a later thermal-distribution update.

## Thermal Battery

Requires stored heat, transfer rates, persistence, charging modes, discharge modes, heat loss, and exploit protection.

Reserve for after the thermal-control system is stable.

## Sulfur Burner

Not currently necessary because the Molten Rotor Furnace already fills the primary heat-generation role.

Only revisit it when sulfur combustion has a unique chemical purpose.

## Impurity Particulate Separator

Fits the mod, but should be the main machine of a dedicated separation and refinement update.

## Cryogenic Mixing

Requires an entire cold-processing system and does not currently connect naturally to the existing progression.

## Smart Perforated Spritzer

Crop detection, logistics requests, fluid ratios, redstone configuration, and automatic refilling are too large for this release.

## Flamethrower Nozzle

Requires pressure, fluid consumption, targeting, particles, damage, ignition, acid handling, and griefing controls.

## Reinforced Crushing Wheel

Should wait until multiple materials genuinely require processing beyond normal Crushing Wheels.

## Litmus Paper

Keep for a future chemistry update with multiple acids, bases, neutralization, and unidentified mixtures.

## Heat-Resistant Apron

Potentially useful, but not necessary for this update unless development finishes ahead of schedule.
