# Security Policy

## Supported Versions

Create: Sulfuric Resonance is currently in beta development.

| Version | Supported |
| --- | --- |
| 0.3.0 | ✅ |
| 0.2.9-beta | ✅ |
| 0.2.8-beta and older | ❌ |

Security fixes will generally target the latest available version of Create: Sulfuric Resonance.

## Reporting a Vulnerability

Please do not report security vulnerabilities through a public GitHub issue.

If private vulnerability reporting is enabled for this repository, use GitHub's **Report a vulnerability** option under the repository's Security section.

When reporting a vulnerability, please include:

- The affected CSR version
- Minecraft version
- NeoForge version
- Create version
- A clear description of the issue
- Steps to reproduce it
- Relevant logs or crash reports
- The potential impact, if known

Please allow reasonable time for the issue to be investigated and fixed before publicly disclosing technical details.

## Regular Bugs

Normal crashes, gameplay bugs, compatibility problems, rendering issues, and feature requests should use the GitHub Issues templates instead.
